# Hifdh Coach

Appli web d'entraînement à la récitation du Coran de mémoire : le texte se dévoile pendant que tu récites au micro, et les mots oubliés ou faux sont signalés.

- 114 sourates (texte Uthmani) + traduction française — données [quran-json](https://github.com/risan/quran-json) (CC BY-SA 4.0)
- Police Amiri Quran (SIL Open Font License)
- Reconnaissance vocale : Web Speech API du navigateur (Chrome ou Safari, connexion internet requise)

Outil d'entraînement : vérifie toujours ta récitation auprès d'un enseignant.
